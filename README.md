## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/parisaMontakhab/parisa-portfolio.git
```

Enter the project directory:

```bash
cd parisa-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```

### Production Build

```bash
npm run build
```
